# FutaNeko Android 試験版

FutaNekoは、掲示板の閲覧・投稿・画像や動画の保存ができるAndroidアプリです。
現在はストア外で試験版を配布しています。

**[Android版をダウンロード](https://github.com/dieOD/futaneko-android/releases/tag/android-1.0.3-6)**

ダウンロード先の「Assets」から **`FutaNeko-Android-1.0.3-6.apk`** を選んでください。
`Source code`や動画部品の資料は、通常のインストールには必要ありません。

**[不具合・要望はこちら（GitHub Issues）](https://github.com/dieOD/futaneko-android/issues)**

- 対応OS: Android 7.0以降。端末によって動作が異なります。
- 対象: Androidスマートフォン。タブレットの表示は十分に確認できていません。
- 料金: この試験版は無料です。
- バージョン: 1.0.3（6）。
- 更新: 新しいAPKをダウンロードして上書きします。自動更新はありません。

## インストール

1. Android端末のブラウザで上のリンクを開き、APKをダウンロードします。
2. ダウンロードしたAPKを開きます。
3. インストールが許可されていない場合は、表示された設定画面で、使用中のブラウザやファイルアプリに対する「この提供元のアプリを許可」をオンにします。項目名は端末によって異なります。
4. APKへ戻り、「インストール」を選びます。
5. 完了後、手順3の許可はオフへ戻して構いません。次回の更新時に必要なら再度許可します。

ダウンロード元がこのページであることを確認してください。端末の保護機能が危険なアプリとして検知・拒否した場合は、保護機能全体を無効にせず、表示内容と端末名を報告してください。

## 更新とデータ

**更新するときにFutaNekoをアンインストールしないでください。**
新しいAPKを開いて更新すれば、通常は設定・履歴・保存スレを引き継ぎます。
アプリの削除やAndroid設定の「ストレージを消去」は、これらのデータを削除します。

OSのバックアップや機種変更で、すべてのデータが移ることは保証しません。
アプリ設定のバックアップ機能で書き出せるのは設定です。履歴、下書き、Cookie、削除キーなどを含む完全バックアップではありません。

## 不具合・要望

[GitHub Issues](https://github.com/dieOD/futaneko-android/issues) で、不具合報告や使い勝手へのご意見、機能の要望を受け付けています。投稿にはGitHubアカウントが必要です。

同じ内容のIssueがないか確認し、見つからなければ「New issue」から投稿してください。同じ内容がある場合は、そのIssueへコメントできます。

不具合の場合は、分かる範囲で次の情報を添えてください。

- 端末名
- OSの種類とバージョン
- FutaNekoのバージョンと括弧内の番号
- 行った操作と、起きたこと

機能の要望は「何に困っているか」「どうなると使いやすいか」を教えてください。

**Issueの本文・コメント・添付画像は公開されます。** 個人情報、パスワード、Cookie、投稿の削除キー、端末の識別番号は載せないでください。スクリーンショットに個人情報が写っている場合は、隠してから添付してください。

GitHubアカウントがない方は、募集スレ、または **futaneko_contact@icloud.com** へお知らせください。これらの窓口にもパスワードやCookieなどを送る必要はありません。
